# 게시판 켜기 — 딱 두 가지만 하시면 됩니다

코드는 이미 다 올라가 있습니다. 아래 두 가지는 **Supabase 화면에서 사람이 직접** 해야 합니다
(비밀번호를 넣어야 하는 일이라 자동으로 대신 해 드릴 수 없습니다).

그 전까지 홈페이지 게시판에는 「게시판을 준비하고 있습니다」라고만 뜹니다. 깨지지는 않습니다.

---

## 1. 표 만들기 (1분)

1. <https://supabase.com/dashboard/project/nevitsamefsohuuaokdi/sql/new> 접속
2. 저장소의 **`docs/게시판_supabase.sql`** 파일을 열어 **통째로 복사**
3. 화면에 붙여넣고 오른쪽 위 **Run** (또는 `Ctrl+Enter`)
4. 맨 아래에 `지금_보이는_글 = 0` 이 나오면 성공입니다

> 두 번 실행해도 안전합니다. 있으면 지우고 다시 만들도록 짜 두었습니다.
>
> 🔴 실행 뒤 Supabase 가 `security_definer_view` 경고를 띄울 수 있는데 **일부러 그렇게 한 것**입니다.
> 승인 안 된 글의 본문을 서버에서 잘라 내보내려면 그 방식이어야 합니다. 이유는 SQL 파일 안에 적어 두었습니다.

## 2. 관리자 계정 만들기 (2분)

승인·삭제는 **로그인한 사람만** 할 수 있습니다. 그 계정을 하나 만듭니다.

1. <https://supabase.com/dashboard/project/nevitsamefsohuuaokdi/auth/users> 접속
2. 오른쪽 위 **Add user → Create new user**
3. 이메일: `koreauniversityforum@gmail.com` (아무 주소나 됩니다)
   비밀번호: 정하고 **따로 적어두세요**
   **Auto Confirm User 를 켜세요** — 안 켜면 메일 인증을 기다립니다
4. 만들고 나서 **Authentication → Sign In / Providers → Email** 로 가서
   **Allow new users to sign up 을 끄세요.**
   🔴 이걸 안 끄면 **아무나 회원가입해서 관리자 권한을 가져갑니다.** 꼭 끄셔야 합니다.

## 다 하고 나면

| 어디 | 무엇 |
|---|---|
| <https://univforum.kr/board> | 방문자가 글 쓰는 곳 |
| <https://univforum.kr/board-admin.html> | 승인 화면 (2번에서 만든 계정으로 로그인) |

## 어떻게 돌아가는가

```
방문자가 글 작성
   → 무조건 「승인 대기」로 저장 (방문자가 상태를 정할 수 없습니다)
   → 목록에는 제목 + 본문 앞 110자만 보임 · 「승인 대기중」 딱지
   → 관리자가 「공개하기」 누르면 전문 공개
   → 「반려」 누르면 목록에서 사라짐 · 「완전히 지우기」 는 되돌릴 수 없음
```

**막아 둔 것**

- 방문자는 표를 **읽지 못합니다.** 잘라 낸 미리보기를 내보내는 창구 하나만 볼 수 있습니다.
  → 광고 글의 전문이 화면 소스에 실려 나가지 않습니다.
- 같은 IP 로 **3분에 2건**까지만 쓸 수 있습니다.
- 링크·연락처(`http`, `카톡`, `010-…`)가 섞이면 관리 화면에 **빨간 표시**가 붙고,
  「표시된 대기글 모두 반려」로 한 번에 치울 수 있습니다.
- 상태를 바꾸거나 지우는 일은 **로그인한 사람만** 할 수 있습니다.
