# 한국대학생포럼 홈페이지 - 운영 안내

## 이 홈페이지가 굴러가는 방식

```
GitHub 저장소  ──(커밋되면 자동으로)──▶  Vercel  ──▶  univforum.kr
     ▲
     │ admin.html 에서 글을 올리면 여기로 커밋된다
```

**HTML 을 고칠 일은 없다.** 소식은 전부 아래 두 파일에 들어 있고,
`admin.html` 이 그 두 파일을 고쳐 준다.

| 파일 | 담는 것 | 보이는 곳 |
|---|---|---|
| `public/data/posts.json` | 한대포 공지·소식 | 첫 화면 소식 칸, `/news`, `/news/[id]` |
| `public/data/newbodae.json` | 뉴보대(@news_univ) 카드뉴스 | 첫 화면·소식 화면의 「뉴스 보는 대학생」 줄 |
| `public/data/events.json` | 행사 일정 | 첫 화면 「곧 만날 수 있는 자리」 |
| `public/media/` | 위 두 곳에 쓰이는 사진 | - |

## 새 인스타 피드를 올렸을 때 (평소 하는 일)

1. `https://univforum.kr/admin.html` 를 연다
2. 왼쪽 위 **「+ 새 글」**
3. 제목 · 날짜 · 인스타 게시물 주소를 넣고, **인스타 캡션을 본문에 그대로 붙여넣는다**
4. **카드 이미지**에서 올린 카드 png 를 고른다 (가로 1080px JPEG 로 저절로 줄어든다)
5. **「이 글을 공지로 올리기」가 켜져 있는지 확인** - 켜져 있으면 지금 공지인 글이 저절로 일반글로 내려간다
6. **「글 저장」** → 아래 **「GitHub에 올리기」**
7. 커밋이 들어가면 Vercel 이 다시 빌드한다. 1~3분 뒤 반영된다. 안 보이면 `Ctrl`+`Shift`+`R`

뉴보대 카드는 위쪽 **「뉴보대 피드」** 탭에서 같은 방식으로 올린다.
**인스타그램 게시물 주소** 칸에 그 카드의 게시물 주소를 넣으면 홈페이지에서 눌렀을 때 그 글로 간다
(비워 두면 `@news_univ` 계정 화면으로 간다).
뉴보대는 공지 개념이 없고, 홈페이지에서 누르면 인스타 게시물로 넘어간다.
첫 화면에는 최근 것부터 대여섯 장이 보이고, **지난 피드는 줄 오른쪽 단추**로 밀어서 본다
(줄에는 최근 24장까지 담긴다 - `NewbodaeRow` 의 `limit`).

### 토큰을 안 넣었을 때

「저장소 설정」을 비워 두면 **「파일로 내려받기」**만 쓸 수 있다.
`posts.json` · `newbodae.json` · 사진들을 받아서 GitHub 웹 화면에서
`public/data/` 와 `public/media/` 에 직접 올리면 결과는 똑같다.

### 토큰 만드는 법 (한 번만)

GitHub → Settings → Developer settings → **Personal access tokens → Fine-grained tokens**
→ Repository access 는 **이 저장소 하나만**, Permissions 는 **Contents: Read and write** 하나만.

> 🔴 토큰은 그 브라우저에만 저장된다(localStorage). 공용 PC 에서는 넣지 말 것.
> 학교 컴퓨터에서 썼다면 「토큰 지우기」를 누르고 나올 것.

## 일정 고치기 (「일정」 탭)

`admin.html` 위쪽 **「일정」** 탭을 누르면 왼쪽이 목록 대신 **달력**이 된다.

- **날짜 숫자**를 누르면 → 그 날짜로 **새 일정**이 시작된다(날짜를 다시 고를 필요가 없다)
- **일정 이름**을 누르면 → 그 일정을 **고친다**
- 지우기는 오른쪽 아래 「이 일정 지우기」
- 다 됐으면 다른 탭과 똑같이 아래 **「GitHub에 올리기」**

받는 칸은 제목 · 날짜 · 시작 시간 · 장소 · 한 줄 안내(본문 칸)뿐이다.
분류·공지·사진은 일정에 필요가 없어 그 탭에서는 아예 숨는다.

### 홈페이지에서 보이는 방법

「곧 만날 수 있는 자리」에는 **목록 / 달력** 고르개가 붙어 있다.

- **목록**(기본): 바로 지난 자리 1건 + 다가오는 자리 2건. 지난 자리는 흐리게 나온다
- **달력**: 그 달을 통째로. 점이 찍힌 날을 누르면 그 날 것만 아래에 펴진다

🔴 **오늘이 며칠인지는 보는 사람의 화면에서 정한다.** 이 홈페이지는 만들어 둘 때 한 번
찍혀 나가므로(SSG), 서버에서 오늘을 정해 두면 배포한 날에 굳어 다음 날부터 거짓말이 된다.
D-DAY 를 손으로 적어 두면 안 되는 것과 같은 이유다.

## 공지는 왜 한 건만인가

「이 글을 공지로 올리기」를 켜고 저장하면 **다른 글의 `pinned` 가 전부 꺼진다.**
그래서 새 피드가 올라올 때마다 자연스럽게

- 새 글 → 공지 (소식 화면 맨 위, 큰 카드)
- 이전 공지 → 그냥 일반글 (아래 목록으로 내려감)

이 된다. 손으로 이전 글을 내릴 필요가 없다.
혹시 실수로 `pinned` 가 여러 개 남아도, 화면은 **가장 최신 것 하나만** 공지로 본다.

## 「함께할 사람들」 카드와 지원 폼

첫 화면 아래 활동 카드는 `components/ClubFilter.tsx` 의 `clubs` 배열에 들어 있다.
카드에 **`href` 가 있으면 통째로 눌리는 링크**가 되고(새 탭), 없으면 안 눌린다.

주소는 컴포넌트에 직접 박지 않고 `lib/site.ts` 의 `CLUB_FORMS` 에 모아 두었다.
폼을 새로 만들면 **거기 한 줄만** 갈아 끼우면 카드가 따라온다.

| 카드 | 지원 폼 |
|---|---|
| 현재를 기록하는 대학생 에디터 클럽 | <https://forms.gle/qm2jD4o62xEdS3yt6> |
| 아이디어를 서비스로! … 사이드 프로젝트 팀 | <https://forms.gle/4VHRHdD26Y9DA4RD7> |
| 한국대학생포럼 회원 모집 | `JOIN_FORM` (가입 신청 폼) |

두 폼은 2026-08-20 에 한대포 계정(`koreauniversityforum@gmail.com`)으로 만들었다.
응답은 각 폼 편집 화면의 **「응답」 탭**에서 본다. 만드는 데 쓴 스크립트와 함정은
바탕화면 `에디터클럽 구글폼 만드는 법.md` 에 적어 두었다.

🔴 **주소가 없는 활동에는 `href` 를 넣지 말 것.** 안 눌리는 카드가 죽은 링크보다 낫다.

## 손대면 안 되는 것

- `public/data/*.json` 안의 **`id`** - 글 주소(`post.html?id=…`)가 이 값이라, 바꾸면 그 글 링크가 죽는다
- `public/media/` 안의 파일 이름 - 위와 같은 이유
- `lib/site.ts` 의 값은 화면 여러 곳이 같이 본다. 문구를 고칠 때는 컴포넌트가 아니라 여기부터 볼 것

## 자동 수집 (아직 잠들어 있음)

`scripts/sync-instagram.mjs` + `.github/workflows/instagram-sync.yml` 이 이미 들어 있다.
토큰을 넣기 전에는 **아무 일도 하지 않고 정상 종료**한다 - Actions 가 초록불인데 조용한 게 정상이다.
켜는 방법은 [`인스타_자동수집_켜기.md`](인스타_자동수집_켜기.md) 참고.

## 확인해야 할 것 하나

인스타 핸들이 자료마다 두 갈래로 적혀 있었다.

- `universityforum_korea` ← 뉴보대 워터마크·설명서에 쓰인 것. **지금 사이트는 이걸 쓴다**
- `universityforum_korea` ← 처음 만든 index.html 에 있던 것

둘 중 어느 쪽이 진짜인지 확인해서, 아니면 `lib/site.ts` 의 `INSTAGRAM.kuf` 한 줄만 고치면 사이트 전체가 따라온다.
