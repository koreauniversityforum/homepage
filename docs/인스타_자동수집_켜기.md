# 인스타 새 글 자동 등록 켜기

지금은 **틀만 깔려 있다.** 아래 세 값을 GitHub Secrets 에 넣는 순간부터
30분마다 인스타를 확인해 새 글을 저절로 올린다.

| Secret 이름 | 넣을 값 |
|---|---|
| `IG_TOKEN` | Meta 장기 액세스 토큰 |
| `IG_USER_KUF` | 한대포 인스타 **비즈니스 계정 ID**(숫자) |
| `IG_USER_NBD` | 뉴보대(@news_univ) 비즈니스 계정 ID(숫자) |

둘 중 하나만 넣어도 그 계정만 돈다.

---

## 왜 이렇게 번거로운가

인스타는 **로그인 없이 남의 피드를 읽는 길을 전부 막았다.** 긁어오는 방식은
막히거나 계정이 제한될 수 있어서 쓰지 않았다. 공식 길은 Meta Graph API 하나뿐이고,
그 길은 아래 조건을 요구한다.

- 인스타 계정이 **프로페셔널(비즈니스/크리에이터) 계정**일 것
- 그 계정이 **페이스북 페이지에 연결**되어 있을 것

개인 계정이면 이 자동화는 못 쓴다. 그때는 `admin.html` 로 손수 올리면 된다
(하는 일은 같고, 30초 걸린다).

> 참고: 예전에 쓰던 **Instagram Basic Display API 는 2024년 12월에 종료**됐다.
> 인터넷에 남아 있는 옛 설명은 대부분 그쪽이라 따라 하면 안 된다.

## 절차

### 1. 계정을 프로페셔널로 + 페이스북 페이지 연결
인스타 앱 → 설정 → 계정 유형 → 프로페셔널 계정으로 전환
→ 설정 → 공유 및 리믹스 / 계정 센터에서 **페이스북 페이지 연결**

### 2. Meta 앱 만들기
<https://developers.facebook.com/apps> → 앱 만들기 → 유형 **비즈니스**
→ 제품 추가에서 **Instagram Graph API** 추가

### 3. 계정 ID 알아내기
그래프 API 탐색기(<https://developers.facebook.com/tools/explorer>)에서
사용자 토큰을 받은 뒤 아래를 차례로 호출한다.

```
GET /me/accounts                     → 페이스북 페이지 목록 (page-id 확인)
GET /{page-id}?fields=instagram_business_account   → 여기 나오는 id 가 IG_USER_*
```

### 4. 장기 토큰으로 바꾸기
탐색기에서 받은 토큰은 1~2시간이면 죽는다. 아래로 **60일짜리**로 바꾼다.

```
GET https://graph.facebook.com/v21.0/oauth/access_token
    ?grant_type=fb_exchange_token
    &client_id={앱ID}
    &client_secret={앱시크릿}
    &fb_exchange_token={짧은토큰}
```

> 🔴 **60일마다 갱신해야 한다.** 달력에 적어 둘 것.
> 토큰이 죽으면 Actions 가 빨간불로 실패하니, 그때 알아채면 된다
> (실패해도 홈페이지는 멀쩡하다 — 새 글이 안 올라올 뿐이다).

### 5. Secrets 에 넣기
저장소 → Settings → Secrets and variables → Actions → **New repository secret**
위 표의 이름 그대로 세 개를 넣는다.

### 6. 한 번 손으로 돌려보기
저장소 → Actions → **「인스타 새 글 가져오기」** → Run workflow
로그에 `인스타에서 N건 확인` 이 찍히면 성공이다.

## 자동으로 올라온 글은 어떻게 되나

- 한대포 계정 새 글 → **가장 최신 글 하나가 공지**가 되고 나머지는 일반글로 내려간다
- 뉴보대 새 글 → 「뉴스 보는 대학생」 줄에 카드로 붙는다
- 제목은 **캡션 첫 줄**에서 뽑는다(해시태그 줄은 건너뛴다). 어색하면 `admin.html` 에서 고치면 된다
- 사진은 `media/` 에 사본을 받아 둔다 — **인스타 CDN 주소는 며칠이면 만료되므로 그대로 링크하면 안 된다**

## 이미 손으로 올린 글과 겹치지 않나

겹치지 않는다. 자동으로 들어온 글에는 `ig` 항목(인스타 게시물 아이디)이 붙고,
다음 번에는 그 아이디를 보고 건너뛴다.
다만 **같은 글을 손으로 먼저 올려 두었다면** `ig` 가 없어 한 번은 중복으로 들어온다.
그때는 `admin.html` 에서 손으로 올린 쪽을 지우면 된다.
