## 2026-11-05 과거 활동 이력 화면 추가

- 요청: 소개 화면(/about) 소개 문단 아래에 「과거 활동 이력」 단추를 두고, 누르면 이력을 볼 수 있게.
- 만든 것
  - `/history` 화면(`app/history/page.tsx`): 연도·종류(기사/칼럼·사설/인터뷰/블로그/논문·그 밖) 알약으로 걸러 보고, 연도별로 묶어 보여 준다. 제목을 누르면 원문이 새 창으로 열린다.
  - 자료 `public/data/history.json`: 외장하드 `F:\한대포\이력과 경력\` 수집본(1,754건) 중 제목에 단체 이름이 들어간 227건을 우선 실었다. 제목·출처·날짜·링크만 싣고 본문은 싣지 않는다(저작권).
  - `lib/history.ts`(파일 읽기, 서버 전용) · `lib/history-shared.ts`(형식·날짜 함수, 브라우저 공용) · `components/HistoryList.tsx`(걸러 보기).
  - 소개 화면 문단 아래 단추(`primary-button compact` → `/history`). 문단이 `.page-head` 의 마지막 p 가 아니게 되어 `.page-lead` class 로 같은 꾸밈을 다시 줬다.
- 판단
  - 선별 전이라 전부를 올리지 않고 「제목에 이름이 있는 것」만 올렸다. 사용자가 선별 화면에서 고른 뒤 「선택 내보내기 JSON」 결과로 `history.json` 의 `items` 를 통째로 바꾸면 된다(배열 그대로 파일로 두어도 읽힌다).
  - 함정: 브라우저 컴포넌트가 `lib/history.ts`(node:fs)를 가져오면 Turbopack 빌드가 「does not support external modules (request: node:fs)」로 깨진다. 그래서 형식·함수를 `history-shared.ts` 로 뗐다.
  - admin.html 에는 아직 이력 편집 칸이 없다. 당분간 JSON 파일을 직접 고친다.
